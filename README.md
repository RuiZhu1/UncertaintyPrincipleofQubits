# Optimal majorization uncertainty relations for two-outcome qubit measurements

Paper draft and numerics based on the research statement
`GTIIT_Letter_of_Intent_Research_Statement.pdf`.

```
paper/
  main.tex            manuscript (revtex4-2, Phys. Rev. A style)
  references.bib
  figures/            generated by code/make_figures.py
code/
  majorization.py     core library: POVMs, Lorenz curves, lattice supremum, analytic bounds
  verify_bounds.py    numerical checks of every theorem / corollary in the paper
  make_figures.py     regenerates paper/figures/*.pdf
  requirements.txt
```

## Main results

For projective qubit measurements with maximal overlap `c = max |<m_i|n_j>|^2`:

| | optimal bound | Shannon consequence |
|---|---|---|
| direct sum `p ⊕ q` | `(1, √c, 1-√c, 0)` | `H(M)+H(N) ≥ h(√c)` |
| tensor `p ⊗ q` | `(w, 1-w, 0, 0)`, `w = (1+√c)²/4` | all Rényi entropies |

The paper also covers general two-outcome POVMs (Theorem 3) and two-outcome
projective measurements in any dimension (Theorem 4).

## Reproduce

```bash
cd code

python make_figures.py       # writes ../paper/figures/*.pdf
cd ../paper

```
